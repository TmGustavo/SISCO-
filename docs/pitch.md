# Kaluz Digital

Kaluz Digital concentra la gestión de afiliados, conductores, vehículos, pagos, alquileres, documentos y servicios turísticos en una plataforma modular. Esta base habilita una primera experiencia navegable para operación administrativa, conductores y clientes, mientras prepara integraciones seguras con Supabase y servicios de IA.

La etapa actual evita pagos reales, GPS en vivo, WhatsApp, IA productiva y conexiones de base de datos. Cada una se incorporará por etapas, con contratos, permisos y validaciones definidos por el equipo.
