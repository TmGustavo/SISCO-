# Kaluz Digital

Aplicación React para la gestión de transporte, afiliados, conductores, vehículos, alquileres y turismo de Kaluz.

## Desarrollo

```powershell
npm install
npm run dev
```

Comprobaciones:

```powershell
npm run lint
npm run typecheck
npm run build
```

El proyecto usa datos simulados. Supabase, IA, GPS, pagos y WhatsApp permanecen sin conexión hasta contar con contratos, permisos y secretos aprobados.

Consulta `docs/` para contratos, tareas, casos de prueba y pitch.
